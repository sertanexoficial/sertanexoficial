# Manutenção da apresentação da SERTANEX

**Muitas possibilidades, uma única conexão.**

Esse é o slogan institucional da SERTANEX. Preserve a frase completa e a pontuação no README, na descrição alternativa e nos banners.

Este repositório contém o README do perfil público `sertanexoficial` e seus banners. Os arquivos SVG são as fontes editáveis dos banners; mantenha os textos como texto e preserve o `viewBox` ao atualizar a arte.

## Conteúdo

- Mantenha nome, localização, e-mail e Instagram consistentes entre o perfil, o README e os banners.
- Preserve a indicação **“PDV e delivery em desenvolvimento”** enquanto esse for o estágio confirmado do projeto.
- Acrescente funcionalidades disponíveis, demonstrações ou datas somente depois de confirmadas pela equipe responsável.
- Priorize links de contato em texto nativo no README. Quando um canal aparecer na capa de compartilhamento, atualize também a arte se ele mudar.

## Identidade visual

| Elemento | Referência |
| --- | --- |
| Fundo principal | Ameixa `#241A2C` |
| Texto principal | Creme `#FFF9F2` |
| Destaques | Coral `#EE603F` |
| Tipografia das artes | Inter, com alternativas Arial e sans-serif |

Preserve o símbolo oficial e use sua fonte em alta resolução ao atualizar o avatar do perfil.

## Ativos

| Arquivo | Uso |
| --- | --- |
| `assets/banner-digital.svg` | Banner digital principal, com 1200 × 360 px |
| `assets/banner-digital-mobile.svg` | Banner digital para telas de até 600 px, com 800 × 500 px |
| `assets/social-preview-digital.svg` | Fonte editável da capa de compartilhamento, com 1280 × 640 px |

Exporte a capa de compartilhamento em PNG com 1280 × 640 px e envie em **Settings → General → Social preview** do repositório institucional. Esse envio é separado dos banners exibidos pelo README.

Os banners usam fundo opaco para preservar o contraste nos temas claro e escuro do GitHub. As fontes do SVG devem ter alternativas comuns, como `Arial, sans-serif`, porque a fonte principal pode não estar disponível durante a renderização.

O README usa `<picture>` para selecionar a composição para celular e mantém uma imagem padrão em `<img>`. O slogan, o estágio do projeto e os canais de contato também aparecem em texto nativo, fora das imagens.

## Conferência após uma edição

1. Abra a prévia do README e confira o perfil publicado em celular e computador.
2. Confira os temas claro e escuro, a leitura do texto, a proporção dos banners e os caminhos das imagens.
3. Verifique os links de Instagram e e-mail e mantenha uma descrição alternativa breve para a imagem.
4. Confira se a apresentação continua descrevendo o estágio real do projeto.

Referência: [imagens responsivas em um README de perfil — GitHub Docs](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github).
